pymif.napari._dataset_helpers.units_kwargs(dataset, requested_axes)[source]

{"units": ...} for napari layers over requested_axes (empty if unavailable).

The ROI / Zrange / CropBox helper layers are scaled in physical units, so they need the same units as the image layers; otherwise napari warns “Inconsistent units across layers” and stops using units for rendering.

pymif.napari._dataset_helpers.points_projection_kwargs()[source]

Keyword arguments that make a napari Points layer show out-of-slice points.

napari 0.9 deprecated out_of_slice_display in favour of projection_mode; rescale_linear is what the old flag mapped to. Older napari versions only know the old flag.
