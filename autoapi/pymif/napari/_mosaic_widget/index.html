pymif.napari._mosaic_widget.skipped_tile_ids(layers, selection, mosaic_path, mode: str | None, all_channels: bool = False) → list[str][source]

Ids of the tiles to leave blank, from the tile layers shown in napari.

mode="visible" skips the tiles whose layer is hidden (eye icon off), mode="selected" the tiles whose layer is not selected in the layer list, None none. Tiles without a layer (e.g. a channel that is not shown) are fused normally. With all_channels the same stack position is skipped in every channel (the ids are then stack names, e.g. "1-x00-y00").

pymif.napari._mosaic_widget.batch_row(*, input_path, microscope: str, output, values: dict, all_groups: Sequence[str], skip_ids: Sequence[str], picked: Sequence[str] | None = None, all_stacks: Sequence[str] = (), all_fields: Sequence[str] = (), flatfield: bool | None = None) → dict[source]

One pymif fuse --batch CSV row from the fusion widget values.

picked are the stack ids picked on the tile map (None: all); the tiles column stays empty (every tile) when they cover all_stacks. The fields column stays empty when values["fields"] is missing or the mosaic has a single field (all_fields); otherwise it names the fields, since an empty cell means the first field. flatfield is the reader’s flat-field option (None: the reader has none, and the column stays empty).
