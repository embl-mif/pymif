Helper function for CLI to convert a dataset to zarr given some parameters.

Parameters

input_pathstr

Input path for the data to be converted.

zarr_pathstr

Output .zarr path.

microscopestr

Microscope used to acquire input data. One of “luxendo”, “opera”, “viventis”, “zeiss”, “zarrv04”, “zarr”.

max_sizeOptional[int]

Max chunk size in MB.

Default: 100

chunk_sizeOptional[List[int]]

Chunk size in TCZYX format, or whatever axes are present in the dataset. Default: None

scene_indexOptional[int]

Scene index for .czi files.

Default: -1

channel_namesOptional[List[str]]

Name of channels.

Example: “-cn bf gfp rfp”

Default: None

channel_colorsOptional[List[str]]

Colors of channels (hex or matplotlib color name)

Example: “-cc 0000FF cyan 00ff00”)

Default: None

zarr_formatOptional[int]

Output zarr format. Zarr v2 maps to NGFF 0.4 and Zarr v3 maps to NGFF 0.5.

Default: 3

downscale_factorOptional[int]

Pyramid downsampling factor.

Example: “-df 1 2 2”)

Default: 2

num_levelsOptional[int]

Number of pyramid levels.

Example: “-nl 3”)

Default: None

subsetOptional[dict]

Axis subset to apply before chunk selection and pyramid generation.

Example: “–subset y=10:100:2;x=20:80”

Default: None

shardsOptional[str | List[int]]

Zarr v3 sharding for the output.

“auto” sizes shards automatically; a shape (matching the dataset’s axes) requests that shard shape explicitly; “none” disables sharding. With zarr_format=2 sharding is set to none with a warning.

Example: “-sh auto”, “-sh 1 1 8 2160 4096” or “-sh none”

Default: “auto”

shard_target_mbOptional[float]

Target uncompressed shard size in MB, used when shards=”auto”.

Default: 1024 (pymif’s own default; unset here means “let pymif choose”)

shard_exclude_axesOptional[List[str]]

Axes that shards=”auto” never merges chunks along.

Example: “-sea t c” (default) or “-sea none” to allow every axis to merge.

Default: None (falls back to pymif’s own default of t, c)

drop_singletonOptional[bool]

Remove singleton t/c/z axes from the output dataset.

Example: “-ds false” to keep them.

Default: True

num_workersOptional[int]

Number of threads used to write the zarr in parallel.

Example: “-nw 4”

Default: None (half of the available cores, capped at 8)

pymif.cli.pymif.mosaic_convert(input_path, zarr_path, microscope: str | None = None, max_size: float | None = 100, chunk_size: List[int] | None = None, scene_index: int | None = None, channel_names: List[str] | None = None, channel_colors: List[str] | None = None, zarr_format: int | None = 3, downscale_factor: Any | None = 2, num_levels: int | None = None, subset: Any | None = None, shards: Any | None = 'auto', shard_target_mb: float | None = None, shard_exclude_axes: Any | None = None, drop_singleton: bool | None = True, num_workers: int | None = None, read_downsample: Any | None = None, projection: str | None = 'none', blend: str = 'sigmoid', sigmoid_steepness: float | None = None, channels: List[str] | None = None, groups: List[str] | None = None, tiles: List[str] | None = None, skip_tiles: List[str] | None = None, midline_axis: str = 'x', out_dtype: str | None = None, read_workers: int = 4, temp_dir: str | None = None, overwrite: bool = False)[source]

Fuse a mosaic into an OME-Zarr image (CLI helper for pymif fuse).

The convert options (max_size … num_workers) have the same meaning as in zarr_convert(), applied to the fused output; subset crops it (z/y/x in output voxels) and selects channels (c). tiles lists the only tiles to fuse (ids as for skip_tiles); the output then fits them. The other options are those of pymif.mosaic_manager.fuse_tiles(): read_downsample is its ds and read_workers its workers.

pymif.cli.pymif.chromatic_shift_correct(input_path: str, zarr_path: str | None = None, *, report_path: str | None = None, shifts: Any = None, reference_channel: Any = 0, extent: str = 'union', order: int = 1, include_groups: bool = True, include_labels: bool = True, overwrite: bool = False, num_workers: int | None = None, fail_on_warning: bool = False, **estimate_kwargs) → Dict[str, Any][source]

Measure the Z chromatic shift of an OME-Zarr image and write a corrected copy.

Without zarr_path only the estimate runs (and is saved to report_path when given). shifts (one value per channel, a report dict or the path to a JSON report) skips the estimate. With fail_on_warning a report with warnings stops before anything is written except the report. Returns the report, or the given shifts.
