Abstract base class for managing microscope image datasets.

Provides shared functionality for reading, writing, visualizing, and managing multiscale image data and metadata.

Subclasses implement two hooks and inherit read():

  • _parse_metadata() – return the normalized metadata dictionary (see pymif.utils.metadata.build_metadata());

  • _build_dask_array() – return one lazy dask array per pyramid level.

Managers can be used as context managers so that any open file handle is closed automatically:

with mm.LuxendoManager("path/to/dataset") as lux:
    lux.to_zarr("out.zarr")
