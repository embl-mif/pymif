pymif.mosaic_manager.readers.detect_microscope(path: str | pathlib.Path) → str | None[source]

Microscope of the acquisition at path, from its layout, or None if not recognised.

  • "opera": a Harmony export (Images/Index.xml), its Images folder or the index;

  • "luxendo": *.lux.h5 files in raw/<stack>/, in <stack>/ or in the folder.

Opera is checked first: it takes a few file checks, Luxendo lists folders (slow for an Opera Images folder of thousands of files on a network drive).
