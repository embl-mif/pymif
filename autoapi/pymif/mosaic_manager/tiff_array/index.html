Lazy, picklable (z, y, x) stack of single-plane TIFF files (one file per plane).

Like H5Array, it holds no open file, so it can be sent to worker processes and needs no close(). Slicing reads only the planes it needs; every plane is decoded in full (chunks is (1, y, x), which the fusion uses to size its regions).

Parameters

paths

One file per plane, in z order. None marks a missing plane, read as zeros.

shape, dtype

(z, y, x) shape and data type, from the metadata (no file is opened).

folder

Folder of relative paths (keeps memory low for plates with many planes).

transform

Optional picklable callable applied to every whole plane after reading (e.g. a flat-field correction). It returns floats, which are rounded and clipped to dtype.
