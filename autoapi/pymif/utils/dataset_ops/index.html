pymif.utils.dataset_ops

Dataset-level operations shared by MicroscopeManager and ZarrManager.

Each function works on a single (data, metadata) pair (a list of dask arrays plus the PyMIF metadata dictionary) so that the single-dataset managers and the multi-dataset ZarrManager (raw + groups + labels) run exactly the same validation code.

Validate updates against (data, metadata) and apply them in place.

Invalid values raise ValueError/TypeError. Channel updates that do not fit the dataset are skipped with a warning (silently when warn_no_channel_axis is false and the dataset has no channel axis). updates must already be filtered with known_updates().

pymif.utils.dataset_ops.infer_downscale_factors(metadata: dict[str, Any]) → int | tuple[int, Ellipsis][source]

Infer the per-spatial-axis downscale factors between pyramid levels 0 and 1.

Returns 2 for single-level data. Isotropic factors are returned as an int; anisotropic ones (e.g. (1, 2, 2)) as a tuple in spatial-axis order, so the original pyramid layout is rebuilt faithfully.

Subset the base level by axis selections and optionally rebuild the pyramid.

Selections on axes the dataset does not have are ignored. Indices are validated against the dataset shape.
