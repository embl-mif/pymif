zarrsmith.utils.metadata.build_metadata(*, size: Sequence[Sequence[int]], scales: Sequence[Sequence[float]], units: Sequence[str | None], channels: Iterable[ChannelInfo], dtype: str, axes: str = 'tczyx', time_increment: float = 1.0, time_increment_unit: str | None = 's', **extra: Any) → dict[str, Any][source]

Assemble the metadata dictionary every manager exposes as .metadata.

Centralizing this guarantees that all managers use the same keys, that units are spelled the NGFF way (micrometer, second …) and that channel colors are always RRGGBB strings.

zarrsmith.utils.metadata.scale_for_level(base_scale: Sequence[float], base_shape: Sequence[int], level_shape: Sequence[int]) → tuple[float, ...][source]

Voxel size of a pyramid level, from the base voxel size and the shapes.

scale_level = base_scale * base_shape / level_shape for every spatial axis, so the physical extent of the volume is preserved across levels. All three arguments are given in the same (spatial) axis order.
