zarrsmith.utils.chromatic_shift

Axial chromatic shift estimation and correction for multichannel volumes.

Light-sheet channels are often offset from each other along Z: the focal planes of different wavelengths do not coincide, and the offset changes every time the system is realigned. The offset is therefore estimated from the sample itself:

  1. A coarse pyramid level is segmented into a sample mask. Its surfaces that face along Z (its lower- and upper-Z sides) are the one structure every channel shares, through background and autofluorescence.

  2. The Z-derivative of each channel is cross-correlated with the reference channel inside a thin band around those surfaces, giving a coarse shift.

  3. Small crops centred on Z-facing surface points are read from a finer level, pre-shifted by the coarse estimate and correlated again. The correlation curves of all crops are summed and the peak, refined to sub-plane accuracy with a parabola fit, gives the final shift. Crops are balanced between the lower and upper surfaces so that channel-dependent edge blur, which biases the two in opposite directions, cancels out.

Lateral (YX-facing) edges are ignored on purpose: their profile is the same at every Z, so they carry no information about an axial offset.

Shifts are corrections in the physical unit of the Z axis (usually micrometers): the value for channel c is the displacement applied to that channel, positive values moving its content towards higher Z indices. The reference channel always gets 0.

zarrsmith.utils.chromatic_shift._ncc_curve(a: numpy.ndarray, b: numpy.ndarray, max_lag: int, weight: numpy.ndarray | None = None) → numpy.ndarray[source]

Normalized cross-correlation of a with Z-shifted windows of b.

b is 2 * max_lag planes taller than a; lag L compares a with b[max_lag + L : max_lag + L + len(a)], so a peak at L means b is displaced by +L planes relative to a. With a boolean weight only those voxels of a take part.

zarrsmith.utils.chromatic_shift.estimate_chromatic_shift(data_levels: Sequence[dask.array.Array], metadata: dict[str, Any], *, reference_channel: int = 0, timepoint: int = 0, coarse_level: int | None = None, refine_level: int | None = 0, max_shift: float | None = None, n_regions: int = 32, crop_yx: int = 64, min_z_normal: float = 0.7, min_correlation: float = 0.2, threshold: float | None = None) → dict[str, Any][source]

Estimate the axial (Z) shift of every channel relative to a reference.

Parameters

data_levels, metadata

Multiscale pyramid (finest first) and normalized ZarrSmith metadata. The axes must include c, z, y and x.

reference_channel

Channel that stays in place; the others are aligned to it.

timepoint

Timepoint used for the estimate when there is a t axis.

coarse_level

Level used for the sample mask and the coarse estimate. None picks the coarsest level with at least 16 Z planes and 32 pixels in Y and X.

refine_level

Level the surface crops are read from. None skips refinement and returns the coarse estimate.

max_shift

Largest shift searched, in the physical unit of the Z axis. None searches up to 10% of the stack depth. Searching wide is cheap: only the coarse level is affected.

n_regions

Number of surface crops used for refinement.

crop_yx

Y and X size of each crop, in pixels of refine_level.

min_z_normal

Minimum |n_z| of the surface normal for a surface voxel to count as Z-facing (1 = exactly horizontal surface).

min_correlation

Crops whose correlation peak is below this are left out.

threshold

Mask threshold on the channel-averaged, 0-1 rescaled coarse image. None uses Otsu.

Returns

dict

JSON-serializable report. shifts holds the correction per channel (pass the whole dict to write_chromatic_shift_corrected()). surface_shifts gives the median per-crop shift on the lower and upper sample surface separately; a large difference between the two points at channel-dependent edge blur rather than a pure offset. spread is a robust standard deviation of the per-crop shifts around their surface median, and regions lists every crop with its position, shift and correlation so position-dependent shifts can be spotted. warnings collects the warnings raised during the estimate (search limit reached, no usable crop…), so pipelines can fail on them without catching Python warnings.

zarrsmith.utils.chromatic_shift.plan_z_extent(nz0: int, z_spacings: Sequence[float], shifts: numpy.ndarray, extent: Extent) → tuple[float, float][source]

Z padding of the output in physical units, as (below, total).

below is the padding added before plane 0 (negative when cropping), total the change in Z extent. Both are whole multiples of the coarsest level’s Z spacing, so every pyramid level is padded by a whole number of planes and the levels stay aligned.

  • "union": grow Z so no channel loses data.

  • "same": keep the input size; data shifted out of the stack is lost.

  • "intersection": crop Z to the planes every channel still covers.

zarrsmith.utils.chromatic_shift.write_chromatic_shift_corrected(source_root: zarr.Group, datasets: Sequence[tuple[str, Any]], path: str | pathlib.Path, shifts: Any, *, extent: Extent = 'union', order: int = 1, overwrite: bool = True, num_workers: int | None = None, progress: bool = True) → zarr.Group[source]

Write a Z-shift-corrected copy of an OME-Zarr store.

datasets are (name, dataset) pairs as yielded by ZarrManager._iter_datasets, the raw image first; each dataset needs data, zarr_data (the source arrays), metadata and path. Every output array copies its source’s chunks, shards, codecs, fill value and dimension names, and every group copies its source attributes, so the output has the structure of the input with only the Z size changed. The applied correction is recorded in the root attribute zarrsmith_chromatic_shift.

Image datasets whose channel count matches shifts are corrected channel by channel. Datasets without a channel axis (labels) follow the reference channel: they are only padded or cropped to the new Z extent. Image datasets with a different channel count are skipped with a warning.
