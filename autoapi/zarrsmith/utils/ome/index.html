zarrsmith.utils.ome.parse_ome_xml(xml: str | bytes | xml.etree.ElementTree.Element, color_format: str = 'ome') → OmePixels[source]

Parse the first <Pixels> element of an OME-XML document.

Missing physical pixel sizes fall back to 1.0 with a warning so that the user knows the voxel size was not recorded in the file.

Parameters

xmlstr, bytes or Element

OME-XML document (or its root element).

color_format{“ome”, “auto”}

"ome" (default) reads integer channel colors as signed 32-bit RGBA as the OME schema prescribes. "auto" additionally accepts plain 24-bit RGB integers, which some writers (Opera) use, and leaves absent colors to the default palette.
