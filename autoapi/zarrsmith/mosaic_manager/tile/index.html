Module Contents

class zarrsmith.mosaic_manager.tile.Tile[source]

One acquired tile of a mosaic: a lazy (z, y, x) array and where it sits.

Placement is translation-only: origin is the position (in units) of voxel [0, 0, 0] in the common sample frame and voxel_size the voxel spacing. All tiles of a mosaic must use the same units and voxel size.

Parameters

data

Anything with shape, dtype and numpy-style slicing that returns array data: an h5py.Dataset, a dask or a numpy array. It is only read when a fusion needs it.

origin, voxel_size

(z, y, x) position of the first voxel and voxel spacing.

channel

Channel (dye) name. Tiles with the same name are fused into one output channel.

group

Optional label of tiles that should be merged among themselves first, e.g. "L"/"R" illumination side. Used by blend="sigmoid" and "midline".

timepoint

Index of the timepoint the tile belongs to (0 for a single timepoint). Mosaics with more than one timepoint are not supported yet: MosaicManager refuses them.

attrs

Free-form, reader specific metadata (stack, grid position, …).

units

Units of origin and voxel_size.

field

Name of the field (connected group of touching tiles) the tile belongs to, e.g. "field0". Set by MosaicManager when the mosaic is loaded (see label_fields()), unless the reader gives one.
