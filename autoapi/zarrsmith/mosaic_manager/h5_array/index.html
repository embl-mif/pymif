class zarrsmith.mosaic_manager.h5_array.H5Array(path: str | pathlib.Path, dataset: str = 'Data', shape=None, dtype=None)[source]

Lazy, picklable view of one HDF5 dataset.

The file is opened for every read, so the object holds no handle: it can be sent to worker processes (which is what lets fuse_tiles() read many tiles in parallel despite h5py’s per-process lock) and needs no close(). It behaves like a read-only array: shape, dtype, ndim and numpy-style slicing, so dask.array.from_array accepts it directly.
