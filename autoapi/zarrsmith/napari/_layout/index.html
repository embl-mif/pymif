zarrsmith.napari._layout.compose_dock(content: qtpy.QtWidgets.QWidget, bottom: qtpy.QtWidgets.QWidget | None = None) → qtpy.QtWidgets.QWidget[source]

Build the dock widget: scrollable content and an optional resizable bottom pane.

  • the logo sits in a slim row above everything, always visible.

  • content (all the boxes) goes in one scroll area, so nothing is ever cut off, whatever the size or position of the dock (side or bottom).

  • bottom (typically the log) sits under a splitter handle, so it can be dragged taller or shorter.

zarrsmith.napari._layout.enable_drag_and_drop(file_edit, transform: Callable[[pathlib.Path], pathlib.Path] | None = None, placeholder: str = 'Drop a file or folder here, or browse', single_only: bool = False) → None[source]

Let a magicgui FileEdit accept a file or folder dropped from the file explorer.

transform maps the dropped path to the value to set (e.g. a file to its folder); by default the dropped path is used as is. Paths are not resolved, so a mapped network drive (Y:\...) keeps its drive letter. With single_only, several files dropped at once are left to the parent widget (e.g. a panel that sorts them out); else the first one is used.
