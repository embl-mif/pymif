zarrsmith.napari._batch_csv

Batch CSV export shared by the napari widgets (no Qt dependency, so unit-testable).

Module Contents

zarrsmith.napari._batch_csv.append_batch_csv(csv_path, row: Mapping[str, object], columns: Sequence[str]) → pathlib.Path[source]

Append row to the batch CSV at csv_path and return the path written.

The file gets a .csv suffix if it has none. columns come first, in that order; columns that an existing file already has are kept after them. An existing file that cannot be read raises instead of being overwritten.
