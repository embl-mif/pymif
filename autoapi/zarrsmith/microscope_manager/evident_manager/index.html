Lazy, read-only TCZYX view of one scene of an Olympus/Evident .vsi file.

Every __getitem__ call reads the requested block with slideio, so dask.array.from_array can wrap it directly. The slideio scene is opened on first use and dropped when pickled, so the object can be sent to worker processes.

full_size is the (width, height) of the full-resolution scene. When shape is smaller in Y/X, the array is one of the lower-resolution levels stored in the file: blocks are requested in full-resolution coordinates and slideio reads them from the matching stored level.

A manager class for reading Olympus/Evident .vsi datasets (cellSens).

A .vsi file only holds the metadata: the pixels live in the companion folder _<name>_/stack*/frame_t*.ets, which must sit next to the .vsi file. Tiled acquisitions are stored already stitched, so a 2 x 2 tile scan is read as one large image. The pixels are read lazily with slideio.

A VSI file can hold several scenes (e.g. an overview and the acquired stack); one scene is loaded at a time and read() can be called again with another scene_index.

cellSens stores lower-resolution levels for large (e.g. tiled) images. These are exposed as further pyramid levels, downsampled in Y and X only, which makes napari 3D rendering of the raw file fast. Single-tile acquisitions usually have only the full resolution. build_pyramid() (used by zarrsmith convert) always rebuilds the pyramid from the full resolution.
