Reader for Luxendo microscope data saved as multi-resolution HDF5 (.lux.h5) and XML metadata.

This class parses Luxendo’s XML configuration and builds a lazy Dask array pyramid for downstream processing. One *.lux.h5 file holds one timepoint and channel (tp-<t> / ch-<c> in the file name); HDF5 handles stay open until close() (or leaving a with block).
