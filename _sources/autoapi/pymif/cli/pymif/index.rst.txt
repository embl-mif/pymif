.. py:function:: zarr_convert(input_path, zarr_path, microscope: Optional[str] = None, max_size: Optional[int] = 100, chunk_size: Optional[List[int]] = None, scene_index: Optional[int] = 1, channel_names: Optional[List[str]] = None, channel_colors: Optional[List[str]] = None, zarr_format: Optional[int] = 3, downscale_factor: Optional[int] = 2, num_levels: Optional[int] = None, subset: Optional[dict] = None, shards: Optional[Any] = 'auto', shard_target_mb: Optional[float] = None, shard_exclude_axes: Optional[Any] = None, drop_singleton: Optional[bool] = True, num_workers: Optional[int] = None)

   Helper function for CLI to convert a dataset to zarr given some parameters.

   Parameters
   ----------
       input_path : str
           Input path for the data to be converted.
       zarr_path : str
           Output .zarr path.
       microscope : str
           Microscope used to acquire input data.
           One of "luxendo", "opera", "viventis", "zeiss", "zarrv04", "zarr".
       max_size : Optional[int]
           Max chunk size in MB. 

           Default: 100
       chunk_size : Optional[List[int]]
           Chunk size in TCZYX format, or whatever axes are present in the dataset.
           Default: None
       scene_index : Optional[int]
           Scene index for .czi files. 

           Default: -1
       channel_names : Optional[List[str]]
           Name of channels.

           Example: "-cn bf gfp rfp"

           Default: None
       channel_colors : Optional[List[str]]
           Colors of channels (hex or matplotlib color name)

           Example: "-cc 0000FF cyan 00ff00")

           Default: None
       zarr_format : Optional[int]
           Output zarr format. Zarr v2 maps to NGFF 0.4 and Zarr v3 maps to NGFF 0.5.

           Default: 3
       downscale_factor : Optional[int]
           Pyramid downsampling factor.

           Example: "-df 1 2 2")

           Default: 2
       num_levels : Optional[int]
           Number of pyramid levels.

           Example: "-nl 3")

           Default: None
       subset : Optional[dict]
           Axis subset to apply before chunk selection and pyramid generation.

           Example: "--subset y=10:100:2;x=20:80"

           Default: None
       shards : Optional[str | List[int]]
           Zarr v3 sharding for the output.

           "auto" sizes shards automatically; a shape (matching the dataset's
           axes) requests that shard shape explicitly; "none" disables sharding.
           With zarr_format=2 sharding is set to none with a warning.

           Example: "-sh auto", "-sh 1 1 8 2160 4096" or "-sh none"

           Default: "auto"
       shard_target_mb : Optional[float]
           Target uncompressed shard size in MB, used when shards="auto".

           Default: 1024 (pymif's own default; unset here means "let pymif choose")
       shard_exclude_axes : Optional[List[str]]
           Axes that shards="auto" never merges chunks along.

           Example: "-sea t c" (default) or "-sea none" to allow every axis to merge.

           Default: None (falls back to pymif's own default of t, c)
       drop_singleton : Optional[bool]
           Remove singleton t/c/z axes from the output dataset.

           Example: "-ds false" to keep them.

           Default: True
       num_workers : Optional[int]
           Number of threads used to write the zarr in parallel.

           Example: "-nw 4"

           Default: None (half of the available cores, capped at 8)

.. py:function:: mosaic_convert(input_path, zarr_path, microscope: Optional[str] = None, max_size: Optional[float] = 100, chunk_size: Optional[List[int]] = None, scene_index: Optional[int] = None, channel_names: Optional[List[str]] = None, channel_colors: Optional[List[str]] = None, zarr_format: Optional[int] = 3, downscale_factor: Optional[Any] = 2, num_levels: Optional[int] = None, subset: Optional[Any] = None, shards: Optional[Any] = 'auto', shard_target_mb: Optional[float] = None, shard_exclude_axes: Optional[Any] = None, drop_singleton: Optional[bool] = True, num_workers: Optional[int] = None, read_downsample: Optional[Any] = None, projection: Optional[str] = 'none', blend: str = 'sigmoid', sigmoid_steepness: Optional[float] = None, channels: Optional[List[str]] = None, groups: Optional[List[str]] = None, fields: Optional[List[str]] = None, tiles: Optional[List[str]] = None, skip_tiles: Optional[List[str]] = None, midline_axis: str = 'x', out_dtype: Optional[str] = None, read_workers: int = 4, temp_dir: Optional[str] = None, overwrite: bool = False, flatfield: bool = True)

   Fuse a mosaic into an OME-Zarr image (CLI helper for ``pymif fuse``).

   The ``convert`` options (``max_size`` ... ``num_workers``) have the same meaning as in
   :func:`zarr_convert`, applied to the fused output; ``subset`` crops it (z/y/x in
   output voxels) and selects channels (c). ``tiles`` lists the only tiles to fuse
   (ids as for ``skip_tiles``); the output then fits them. ``fields`` keeps only the
   tiles of these fields (connected groups of touching tiles, ``field0``, ``field1``...);
   without ``tiles`` and ``fields`` the first field is fused. Tiles from several fields
   are not fused: an error is printed and ``False`` returned (``True`` once the output
   is saved). The other options are those of
   :func:`pymif.mosaic_manager.fuse_tiles`: ``read_downsample`` is its ``ds`` and
   ``read_workers`` its ``workers``. ``flatfield`` is passed to readers that correct
   the tiles (Opera); the others ignore it.

.. py:function:: _print_shift_report(report: Dict[str, Any]) -> None

.. py:function:: chromatic_shift_correct(input_path: str, zarr_path: Optional[str] = None, *, report_path: Optional[str] = None, shifts: Any = None, reference_channel: Any = 0, extent: str = 'union', order: int = 1, include_groups: bool = True, include_labels: bool = True, overwrite: bool = False, num_workers: Optional[int] = None, fail_on_warning: bool = False, **estimate_kwargs) -> Dict[str, Any]

   Measure the Z chromatic shift of an OME-Zarr image and write a corrected copy.

   Without ``zarr_path`` only the estimate runs (and is saved to
   ``report_path`` when given). ``shifts`` (one value per channel, a report
   dict or the path to a JSON report) skips the estimate. With
   ``fail_on_warning`` a report with warnings stops before anything is
   written except the report. Returns the report, or the given shifts.
